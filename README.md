## 🚀 Overview

BytePulseAI is a high-converting, modern landing page built with React 19, TypeScript, Vite, and Tailwind CSS v4. Designed with a sleek, futuristic dark-mode aesthetic (`#0B0F19`) featuring electric cyan (`#00F2FE`) and glowing purple/magenta (`#9B51E0`) accents.

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm 9+

### Installation & Run
```bash
# Navigate to project directory
cd "D:\inshal\MY GIT\BytePulseAI"

# Start Vite development server
npm run dev

# Or build for production
npm run build

# Preview production build
npm run preview
```
